# MML 4.0 Site Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Mobile-first public site + phone-first admin for MML 4.0 with live scores, scorers, formations, standings, sponsors and a scroll-driven Kerala → Milan story.

**Architecture:** React SPA (Vite) talking directly to Supabase (Postgres + RLS + Realtime + Auth + Storage). All tournament logic that can be pure (standings, fixtures, score, clock, knockout seeding) lives in `src/lib/` with unit tests; UI reads one shared tournament store kept fresh by Realtime.

**Tech Stack:** Vite 6, React 19, react-router 7, @supabase/supabase-js 2, Vitest. Fonts: Bebas Neue + DM Sans (Google Fonts).

**Spec:** `docs/superpowers/specs/2026-11-19-mml4-site-design.md`

## Global Constraints
- Palette: navy `#0B2A3E`, red `#C8373A`, off-white `#F4F1EA`; halftone-dot textures.
- Headlines Bebas Neue, body DM Sans.
- Match = one half of 10 minutes, default from `settings.match_minutes = 10`.
- Format: 5-team single round-robin (10) → SF 1v4, 2v3 → Final. 13 matches.
- Squad ≤ 10 players; positions exactly `GK | DEF | MID | FWD`; plus manager + team director text fields.
- Tie-breakers: points → GD → GF → head-to-head points → manual `teams.tiebreak_rank`.
- Knockout draw → penalties (`home_pens`/`away_pens`).
- Public read-only; writes only for authenticated users (RLS).
- Sponsor logos on white tiles; Adlers Lombard = tier `title`.
- Footer: "Organised by Milan Malayali Network · Tech partner CAC (calcioac.com)".
- Story must not block scores: pinned LiveBar always visible; `prefers-reduced-motion` → static frames.

## Review Focus
1. Own goal → counted for the *other* team and excluded from top scorers. (Task 1 test)
2. Undo last goal while live → score drops back, public page updates. (Task 1 test: score derived from events)
3. Ties in table (equal pts/GD/GF) → head-to-head then manual rank, never random reorder between refreshes. (Task 1 test)
4. Clock past 10:00 → minute shows "10+1", never resets or goes negative after pause/resume. (Task 1 test)
5. Knockout teams before group is complete → show "1st Group" placeholders, not wrong teams. (Task 1 test)

### Task 1: Pure tournament logic

**Files:** Create `src/lib/{score,standings,fixtures,clock,formations}.js`, tests `src/lib/logic.test.js`.

**Interfaces (Produces):**
- `scoreOf(match, events) -> {home:number, away:number}` — counts `goal` and `own_goal` by `event.team_id` (team credited).
- `computeStandings(teams, matches, events) -> Row[]` where `Row={team_id,p,w,d,l,gf,ga,gd,pts}`, sorted per tie-breakers; only group matches with `status==='ft'`.
- `topScorers(events, players) -> {player_id,name,team_id,goals}[]` (type `goal` only, desc, then name).
- `roundRobin(teamIds) -> [home,away][]` 10 pairs for 5 teams, no team twice in a row where possible.
- `resolveKnockouts(matches, standings, groupDone:boolean) -> matches` filling SF/final team ids from `home_source` like `"G1"`,`"G4"`,`"W:SF1"`; null when not decidable.
- `matchMinute(match, nowMs, matchMinutes) -> {min:number, label:string}`; label `"7'"`, `"10+2'"`, `"FT"`, `""`. Elapsed = `clock_offset_s + (status==='live' ? (now - clock_started_at)/1000 : 0)`.
- `FORMATIONS: Record<'2-2'|'1-2-1'|'2-1-1'|'3-1'|'1-1-2', {x,y}[]>` 5 slots incl. GK at index 0, coords 0–100.
